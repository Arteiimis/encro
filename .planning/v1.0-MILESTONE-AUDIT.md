### 🔴 BLOCKER: `selectPackPlanIndexes` drops `PackPlan::compact`

**File:** `src/pack/pack_service.cpp:94-115`
**Affected flow:** `--full-progress --pack` with job state active

When job state is active (default for all video encoding workflows), `prepareResumablePackExecution` calls `selectPackPlanIndexes()` which constructs a new `PackPlan` but omits `.compact = plan.compact`. The field defaults to `true`, silently overriding the caller's explicit `false`.

**Impact:** User runs `encro --full-progress --pack` → encoding shows per-worker bars ✓ → packing **reverts** to single "Packing: X/Y" bar instead of per-archive bars.

**Fix:** Add `.compact = plan.compact` to the designated initializer in `selectPackPlanIndexes` return statement (line ~115).

### 🟡 WARNING: Implicit struct-default coupling

- `buildDirectoryPackPlan` (packer.cpp:775) — never sets `.compact`, relies on struct default `true`
- `buildPicturePackPlan` (picture_process.cpp:608) — never sets `.compact`, relies on struct default `true`

Working today but fragile. Recommend explicit `.compact = true`.
