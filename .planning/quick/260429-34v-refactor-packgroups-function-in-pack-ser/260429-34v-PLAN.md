   - Calls `ctx.addBar(initialStatus, progress::Tone::Packing)` → stores in `barIndex`
   - Calls `ctx.setProgress(barIndex, 0.0f)`, `ctx.setPostfixText(barIndex, initialStatus)`

   ```cpp

   ```
   - Creates `spinnerThread = std::jthread{[this, &onCompactStatusText](std::stop_token stopToken) { ... }}`
   - Spin loop: 120ms sleep, checks `finalizingCount > 0`, updates bar postfix with `"Finalizing {frame}"` and calls `onCompactStatusText(finalizingText)`

4. **Extract `tryUpdateStatus()` method** — unified bar-setter (per D-04), replaces BOTH lines 284-302 AND lines 320-341:
   ```cpp

                        std::function<void(std::string_view)> const& onCompactStatusText)
   ```
   - Checks `finalizingCount.load(std::memory_order_acquire) == 0`
   - If zero: calls `ctx.setPostfixText(barIndex.value(), statusText)` (guarded by `barIndex.has_value()`)
   - If zero: calls `onCompactStatusText(statusText)` (guarded by truthiness check)
   - Thread-safe: caller holds `mutex` lock (or caller acquires lock before calling — document in comment)

5. **Extract `finish()` method** — replaces lines 367-378:
   ```cpp
   void finish(std::size_t archiveCount,
               std::function<void(std::string_view)> const& onCompactStatusText)
   ```
   - Sets `spinnerStop.store(true, std::memory_order_release)`
   - Calls `spinnerThread.request_stop()` then `spinnerThread.join()`
   - Calls `formatCompactPackedStatus(archiveCount, archiveCount)` for completed status
   - Calls `ctx.setTone(barIndex.value(), progress::Tone::Success)`
   - Calls `ctx.setPostfixText(barIndex.value(), completedStatus)`
   - Calls `onCompactStatusText(completedStatus)` if set

## Threat Model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `CompactProgressState::mutex` → shared atomic fields | Multiple task threads access `completedFileCount`, `barIndex` for progress updates. Mutex serializes postfix/status-text writes. |
| `std::jthread spinnerThread` → `finalizingCount` / `spinnerStop` atomics | Spinner thread reads atomics set by pack worker threads; no mutex needed (atomics with acquire-release ordering). |

### STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34v-01 | Tampering | `CompactProgressState` fields shared across threads | mitigate | Preserve existing `std::scoped_lock{mutex}` pattern from original code for all non-atomic field access. No new shared state beyond what already existed. |
| T-34v-02 | Denial of Service | Spinner thread lifecycle | mitigate | Preserve existing `spinnerStop` atomic + `request_stop()` + `join()` sequence. `finish()` method replicates the exact original shutdown order. |
| T-34v-03 | Information Disclosure | Status text callbacks | accept | No new data flows. `onCompactStatusText` and `onCompactProgress` callbacks unchanged — same format strings, same callback targets. |

**Note:** This is a pure structural refactor. No new trust boundaries, no new data flows, no new external interfaces. All thread-safety mechanisms are preserved exactly as implemented in the original code.
