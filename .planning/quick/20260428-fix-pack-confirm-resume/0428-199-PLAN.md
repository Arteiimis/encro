### Step 2: Add resume-detection confirmation gate

In `runScannedEncodingWorkflow()` (line 265), insert the following block **between** the interruption check end-brace (line 301: `}` of `maybeHandleInterruptedEncoding`) **and** the `maybePackWorkflowOutputs()` call (line 303–304: `auto const packRes = maybePackWorkflowOutputs(...)`):

```cpp
  if (prepared.pendingVids.empty() && !prepared.initialResults.empty() && ctx.config.packOutput) {
    auto const proceed = readUserIpt(
      ctx.config.yesToAll,
      "All encodes already complete. Do you want to proceed with packing? (y/N): "
    );
    if (!proceed) {
      terminal::println(Warning, "Packing task canceled by user.");
      return 0;
    }
  }
```

**Detection logic:**
- `prepared.pendingVids.empty()` → all encoding tasks are already succeeded (nothing to encode)
- `!prepared.initialResults.empty()` → tasks were recovered from prior state (confirms resume scenario, excludes fresh runs)
- `ctx.config.packOutput` → user requested packing via `--pack`/`-p` flag

**Placement rationale:**
- After interruption check (lines 296-301) — if the user hit Ctrl+C, we want the cancel path, not the confirmation prompt
- Before `maybePackWorkflowOutputs()` (line 303) — the gate is exactly where packing is about to start

**Behavior matrix:**

| Scenario | pendingVids | initialResults | packOutput | Prompt Shown? | Outcome |
|---|---|---|---|---|---|
| Fresh run, all pending | non-empty | empty | true | No | Encode → auto-pack |
| Fresh run, all pending | non-empty | empty | false | No | Encode only |
| Resume, all done, packing requested | empty | non-empty | true | **Yes** | User confirms → pack |
| Resume, all done, packing not requested | empty | non-empty | false | No | Clean exit |
| Resume, some remaining | non-empty | non-empty | true | No | Encode rest → auto-pack |
| `--yes`/`-y` with resume | empty | non-empty | true | No (yesToAll=true) | Auto-pack |

**Per D-02 (Prompt Wording):** Uses exact string `"All encodes already complete. Do you want to proceed with packing? (y/N): "`

**Per D-03 (--yes/-y Flag):** `readUserIpt()` automatically returns `true` when `ctx.config.yesToAll` is set, skipping the prompt.

**Per D-04 (Picture path):** No modification to picture path — it already has `confirmPicturePack()` at `picture_process.cpp:290-295`.
