### 2. Added resume-detection confirmation gate (lines 304-313)

Inserted a confirmation block in `runScannedEncodingWorkflow()` between the interruption check (`maybeHandleInterruptedEncoding`) and the pack call (`maybePackWorkflowOutputs`):

```cpp
if (prepared.pendingVids.empty() && !prepared.initialResults.empty() && ctx.config.packOutput) {
    auto const proceed = readUserIpt(
      ctx.config.yesToAll,
      "All encodes already complete. Do you want to proceed with packing? (y/N): "
    );
    if (!proceed) {
      terminal::println(Warning, "Packing task canceled by user.");
      return 0;
    }
  }
```

**Detection logic:**
- `prepared.pendingVids.empty()` — all encoding tasks already succeeded (nothing to encode)
- `!prepared.initialResults.empty()` — tasks recovered from prior state (confirms resume, excludes fresh runs)
- `ctx.config.packOutput` — user requested packing via `--pack`/`-p`

**Behavior matrix verified:**

| Scenario | Prompt Shown? | Outcome |
|---|---|---|
| Fresh run, all pending | No | Encode → auto-pack |
| Resume, all done, packing requested | **Yes** | User confirms → pack |
| Resume, some remaining | No | Encode rest → auto-pack |
| `--yes`/`-y` with resume | No (yesToAll) | Auto-pack |
