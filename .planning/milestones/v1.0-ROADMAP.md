# Milestone v1.0: Compact Progress Mode

**Status:** ✅ SHIPPED 2026-04-26
**Phases:** 1-2
**Total Plans:** 3

## Overview

Add compact/simple progress bar mode for the video encoding + packing pipeline. Instead of showing per-worker progress bars, display a single unified progress bar tracking the entire encode→pack workflow by default. Full progress mode opt-in via `--full-progress` flag.

## Phases

### Phase 1: Compact Progress Mode

**Goal**: Add a compact/simple progress bar mode for the video encoding + packing pipeline. Instead of showing per-worker progress bars, display a single unified progress bar tracking the entire encode→pack workflow.
**Depends on**: None
**Plans**: 2 plans

Plans:
- [x] 01-01: CLI foundation (`--full-progress` flag) + encoding compact mode
- [x] 01-02: Packing compact mode (single overall bar)

**Details:**
Plan 01-01 added `--full-progress`/`-F` CLI flag, `AppConfig::fullProgress` boolean field, and `EncodingProgressState` compact mode with a 5th constructor parameter `bool compact = false`. In compact mode (default), batch encoding shows a single overall bar with no per-worker slot bars. `barIndexOpt()` safe accessor added for optional slot bar indexes. `runEncodingTasks` wires `compact = !ctx.config.fullProgress`.

Plan 01-02 added `PackPlan::compact` field (default `true`), a 2-arg `packFilesToZip` no-progress overload, and `packGroups` compact mode with single "Packing: X/Y" overall bar using an atomic counter. `packEncodedVideos` wires `.compact = !ctx.config.fullProgress`. Picture packing and pack-only workflows inherit default `compact = true` (no changes needed).

## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**
- Decision: Compact mode is default, `--full-progress` is opt-in (Rationale: Cleaner UX, less terminal noise)
- Decision: `compact = !ctx.config.fullProgress` — same pattern in both encoding and packing (Rationale: Consistent flag semantics across subsystems)
- Decision: All PackPlan builders now explicitly set `.compact` — no implicit struct-default reliance (Rationale: Defensive coding, prevents silent regression if default changes)

**Issues Resolved:**
- Fixed `selectPackPlanIndexes` dropping `.compact` field (breaking `--full-progress` packing with job state)
- Eliminated implicit struct-default coupling in `buildDirectoryPackPlan` and `buildPicturePackPlan`

**Issues Deferred:**
- VERIFICATION.md not created for either phase (process artifact gap, tests compensate)
- compress-picture path (`picture_process.cpp:467-475`) still has implicit `.compact` struct-default (low risk)

**Technical Debt Incurred:**
- None introduced — all fixes were closing pre-existing audit gaps
