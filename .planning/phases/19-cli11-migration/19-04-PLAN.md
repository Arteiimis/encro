<objective>
Update xmake.lua to add CLI11 as a build dependency and remove boost::program_options from all targets.

Purpose: Make CLI11 headers available for compilation and signal that boost::program_options is no longer needed. Since Phase 18 already has `add_requires("cli11")` in xmake.lua, the primary work is adding `"cli11"` to the package lists and removing `"boost"` (which includes program_options). However, boost is still needed for other modules (json, filesystem, stacktrace, uuid, process, lexical_cast, program_options for now until all consumers are migrated). We must NOT remove `add_requires("boost[all]")` entirely — that would break boost::json, boost::process, etc. Instead, we need to ensure `cli11` is listed in `add_packages` for both `encro` and `tests` targets, and verify it's already in `add_requires`.

Output: Updated xmake.lua with CLI11 wired into all targets.
</objective>
