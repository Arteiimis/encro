**Change 1: Add translation helper function in the anonymous namespace** (around line 17, after the existing helper functions)

Add this function:
```cpp
// Translate AppConfig naming settings to NamingStrategy.
// Mapping (per D-06 research resolution):
//   {Flat, forceConflictHandling=false}  → NamingStrategy::Flat
//   {Flat, forceConflictHandling=true}   → NamingStrategy::FlatWithForce
//   {Keep, any}                          → NamingStrategy::Keep
auto toNamingStrategy(appctx::AppConfig const& config) -> pack::NamingStrategy {
    if (config.outputLayout == appctx::OutputLayout::Keep) {
        return pack::NamingStrategy::Keep;
    }
    if (config.forceNameConflictHandling) {
        return pack::NamingStrategy::FlatWithForce;
    }
    return pack::NamingStrategy::Flat;
}
```
