## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Tampering | CLI11 flag parsing | accept | CLI11 handles all input validation; `--log-json` is a simple boolean flag with no value input and no injection surface |

| T-04-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed -- all dependencies already in project |
