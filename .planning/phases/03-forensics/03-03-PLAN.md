    When the `detail` argument comes from `inputPath.string()` or `std::format(...)`, the temporary std::string must outlive the ScopedErrorContext. Pattern:
    ```cpp

    auto inputPathStr = inputPath.string();                     // local variable
    logging::ScopedErrorContext ctx("video.scan", inputPathStr); // string_view points to local
    ```
