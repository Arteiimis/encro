<objective>
Simplify picture consumer code by removing all grouping/naming lifecycle types and functions:
`buildPicturePackPlan`, `PreparedPicturePack`, `preparePicturePack`, `printPicturePackWorkflowSummary`,
`PicturePackNamingState`, `buildPicturePackBaseName`.

The non-compress picture path now calls `pack::execute()` directly with a `NamingConfig` (containing
`baseName`) and an `entryNameForFile` callback to inject picture-specific entry names.

Purpose: All grouping and naming logic is owned by the pack module. Picture consumer only provides
entry name data through the callback. This eliminates the picture-to-pack impedance mismatch.

Output: `src/picture/picture_process.cpp` (simplified), `src/picture/picture_process.h` (trimmed).
</objective>

      [plannedEntryNames = std::move(plannedEntryNames)](fs::path const& filePath) {
