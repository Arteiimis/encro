| Version string → terminal output | Hardcoded "encro v1.6 (build: ...)" — no user input in version output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01 | Tampering | cmd.cpp --version flag | mitigate | --version is a boolean flag — no user-controlled values cross into output. Version string is a compile-time literal, compileTimestamp() uses `__DATE__`/`__TIME__` macros (compiler-controlled, not runtime user input). |
| T-20-02 | Information Disclosure | app_entry.cpp version output | accept | Version string contains only public info (v1.6 label + build timestamp). No secrets, paths, or system state exposed. Same information as existing helpIntroLine(). |
| T-20-03 | Denial of Service | cmd.cpp --version flag | accept | --version exits immediately (no processing pipeline). Cannot be combined with resource-intensive flags to trigger work. |
</threat_model>
