Design notes per D-04:
- Each wrapper uses `static` local instances for zero lifecycle management burden
- Functions that are static in PackService (selectPackPlanIndexes, resolveZipNameForIndex, resolveProgressLabelForIndex, appendOrdinalRangeSuffix, defaultZipNameForIndex, defaultProgressLabelForZipName, buildGroupOrdinalRanges) call via `PackService::methodName` — no instance needed
- Functions that need an instance use `static pack::Packer packer; static pack::PackService service(packer);`
- All wrappers `[[deprecated]]` with migration hint to OO API
