<action>
In `pack_types.h`, before `struct PackPlan`:

1. Add new struct:
```cpp
struct PackProgressCallbacks {
    std::function<void(std::size_t)> onGroupStart;
    std::function<void(std::size_t, std::filesystem::path const&)> onGroupSuccess;
    std::function<void(std::size_t, std::string const&)> onGroupFailure;
```

   - `std::function<void(std::size_t, std::string const&)> onGroupFailure;`
   - `std::function<void(std::size_t, std::size_t)> onCompactProgress;`
   - `std::function<void(std::string_view)> onCompactStatusText;`

3. Replace with single field:
   - `PackProgressCallbacks progressCallbacks{};`

4. Remove unused `#include <functional>` if PackPlan no longer directly uses std::function (check other fields — `zipNameForIndex`, `progressLabelForIndex` still use std::function, so keep include).

5. `static_assert(std::is_aggregate_v<pack::PackPlan>)` line 51-54 stays verbatim — sub-aggregates preserve aggregate status.
</action>
